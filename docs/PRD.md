# PRD：線上算命系統

## 1. 專案概述
- **背景與動機**：現代人生活壓力大，常需要尋求心靈寄託或決策參考。將傳統算命、占卜、抽籤等活動線上化，能讓使用者隨時隨地獲得指引，並提供數位化的保存與分享方式。
- **目標用戶**：對命理、占卜有興趣者；面臨人生抉擇、需要方向指引者；喜歡嘗試各種心理測驗或運勢分析的年輕族群；有信仰或習慣求籤祈福、尋求心靈慰藉的民眾。
- **核心價值主張**：提供便捷、隱私且富有趣味性的線上命理服務，讓傳統信仰與現代科技結合，隨時隨地安定人心。

## 2. 功能需求
1. **多樣化算命與占卜（算命、占卜、抽籤）**
   - 作為一名愛好命理的使用者，我希望能在系統上進行多種形式的算命（如線上抽籤、塔羅牌、八字等），以便我能根據當下需求獲得不同的指引。
2. **儲存與管理算命結果**
   - 作為一名使用者，我希望系統能自動儲存我的每一次算命成果與籤詩解析，以便我日後回顧與驗證。
3. **線上捐獻（捐香油錢）**
   - 作為一名虔誠的使用者，我希望能透過系統線上捐獻香油錢，以便我在獲得指引與祈福後，也能表達誠心並支持平台或虛擬廟宇。
4. **會員註冊與登入系統**
   - 作為一名重視隱私的使用者，我希望能建立專屬帳號密碼，以便系統能安全地保存我的個人資料與歷史算命紀錄。
5. **算命結果分享**
   - 作為一名熱愛分享的使用者，我希望能將有趣的或神準的算命結果分享到社群媒體，以便與親友交流討論。

## 3. 非功能需求
- **技術限制**：
  - 前端與後端整合：使用 Flask 框架搭配 Jinja2 模板引擎進行開發。
  - 資料庫：使用 SQLite 作為關聯式資料庫儲存使用者資料與算命紀錄。
- **效能與安全考量**：
  - 密碼安全：需將會員密碼進行加密（如使用 bcrypt 或 Werkzeug 內建功能）。
  - 交易安全：金流串接（捐香油錢）時需確保資料傳輸的安全性，初期可考量串接第三方支付的測試環境（如綠界 API）。
  - 使用者體驗：確保頁面載入速度快，抽籤或占卜的網頁動畫順暢不卡頓。

## 4. MVP 範圍
- **Must Have（必須要有）**：
  - 基礎會員系統（註冊、登入與登出）。
  - 至少一種核心算命功能（建議先實作「線上抽籤」或「每日運勢」）。
  - 將個人的算命結果存入資料庫，並提供歷史紀錄頁面供查看。
- **Should Have（應該要有）**：
  - 第二種或以上的算命占卜功能（例如：塔羅占卜）。
  - 線上捐香油錢功能（可先實作虛擬扣款、金流按鈕或串接測試版 API）。
- **Nice to Have（有了更好）**：
  - 按鈕：分享你的籤詩至社群媒體。
  - 首頁的每日運勢推播提醒。
